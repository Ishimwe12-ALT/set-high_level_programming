# Python - Input/Output

This project covers reading, writing, appending, JSON serialization/deserialization, class dictionary representations, and stream processing in Python 3.

## Tasks Overview
* **0-read_file.py**: Reads a UTF-8 text file and prints it to stdout.
* **1-write_file.py**: Writes a string to a UTF-8 text file.
* **2-append_write.py**: Appends a string to the end of a UTF-8 text file.
* **3-to_json_string.py**: Returns the JSON representation of an object (string).
* **4-from_json_string.py**: Returns a Python data structure represented by a JSON string.
* **5-save_to_json_file.py**: Writes an object to a text file using a JSON representation.
* **6-load_from_json_file.py**: Creates an object from a JSON file.
* **7-add_item.py**: Script that adds all command-line arguments to a list and saves them in a JSON file.
* **8-class_to_json.py**: Returns the dictionary description with simple data structure for JSON serialization of an object.
* **9-student.py**: Class Student defining a student and its JSON representation.
* **10-student.py**: Class Student with filtered JSON representation capability.
* **11-student.py**: Class Student capable of JSON representation and reloading from JSON.
* **12-pascal_triangle.py**: Computes Pascal's triangle of size n.
* **100-append_after.py**: Inserts a line of text into a file after each line containing a specific string.
* **101-stats.py**: Script reading stdin line by line and computing metrics.
