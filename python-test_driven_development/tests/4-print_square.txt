=============================
How to Use 4-print_square.py
=============================

This library defines ``print_square(size)``.

Usage
=====

    >>> print_square = __import__('4-print_square').print_square
    >>> print_square(2)
    ##
    ##
    >>> print_square(0)

Invalid sizes:

    >>> print_square(-1)
    Traceback (most recent call last):
        ...
    ValueError: size must be >= 0
