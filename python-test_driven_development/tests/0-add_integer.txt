=============================
How to Use 0-add_integer.py
=============================

This library defines an addition function ``add_integer(a, b=98)``.

Usage
=====

Checking basic additions:

    >>> add_integer = __import__('0-add_integer').add_integer
    >>> add_integer(1, 2)
    3
    >>> add_integer(100, -2)
    98
    >>> add_integer(2)
    100
    >>> add_integer(100.3, -2)
    98

Handling floats:

    >>> add_integer(2.5, 2.5)
    4

Handling non-numbers:

    >>> add_integer(4, "School")
